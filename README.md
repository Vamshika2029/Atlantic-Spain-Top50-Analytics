# Spain Top 50 Playlist Analytics

## Content Maturity, Release Lifecycle & Playlist Rotation

**Organization:** Atlantic Recording Corporation  
**Project:** Music Analytics  
**Domain:** Data Analytics and Music Industry

## Project Overview

This project analyzes the Spain Top 50 music playlist to understand song lifecycle, playlist rotation, content maturity and popularity patterns.

The objective is to identify how songs enter the playlist, how long they remain, how their popularity changes and what patterns influence playlist retention.

## Project Objectives

- Analyze song lifecycle and chart longevity.
- Identify new, growth, peak, mature and decline stages.
- Measure playlist entries, exits and retention.
- Compare explicit and clean songs.
- Compare singles and album tracks.
- Examine popularity changes throughout the song lifecycle.

## Dashboard

The Streamlit dashboard contains:

- Project Overview
- Song Lifecycle
- Playlist Rotation
- Content Maturity
- Popularity Analysis

## Key Findings

- 575 unique song-artist combinations were analyzed.
- Average observed chart duration was approximately 48.3 days.
- Average playlist retention was approximately 96.56%.
- Average popularity increased from approximately 55.99 at first observation to 72.54 at last observation.

These findings describe the analyzed dataset and its observation period.

The project provides insights into music playlist performance, song longevity, content characteristics and playlist rotation. The dashboard presents the findings through interactive visualizations to support data-driven music industry analysis.
